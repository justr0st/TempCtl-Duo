    How this reads 9.3

    • Sequence: phases run one after another. In a Both phase the bottom setpoint jumps (or the bottom is Idle) and the top ramps and holds; the phase lasts as long as the top part.
    • "Wait for bottom": in a Bottom phase the hold starts only when the bottom PV is inside the band; in a Both phase the top ramp starts only then. Next phase skips the wait.
    • Timeline: two step lists started together, no waits, Next phase disabled. A channel that finishes first keeps its last target until the other is done.
    • Edits during a run change the running copy. You are asked after the run whether to save them.
    • Target changes keep ramp slopes; the times adapt. In a hold, the setpoint ramps to the new target with the step's slope while the hold timer keeps running. A later ramp keeps its slope too.
    • Timeline during a run: when one channel's timing changes, the other channel is shifted by the same time through its holds only — the first hold at or after that moment gets longer (or holds get shorter). Its ramps are never changed or paused.
    • Outside a run, timeline channels are edited independently.
    • The forecast (dashed) uses the programmed times and treats every "wait for bottom" as already satisfied, like the preview in the spec. The real run shows the wait when it happens, and the forecast moves with it. So when the program is not running, a hold can be dragged back to the end of its ramp.
    • A channel that keeps the target of an earlier phase (e.g. the bottom during Top phases), or a timeline channel that is already done, can still get a new target. It moves there with the slope of the step that set it (a jump for a bottom jump). The change is stored in that earlier phase or step of the running copy.
    • Chart handles: target squares (in the middle of a hold) drag up and down; ramp-end diamonds and hold-end circles drag left and right. During a run, finished and current ramps have no ramp handle (ramp times are locked there, as in the table).
    • Thermal model: bottom slow (max 1.1 °C/s), top IR fast (max 3.5 °C/s); not tuned to real hardware.
