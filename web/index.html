    Modbus tools

    No channel is set to Modbus (Channels page).

    Find the setpoint address

    Not needed for the PMA KS 4x-1 (preset). For other controllers: reads every register in the range and lists those whose value equals the controller's effective setpoint. Make sure no ramp is active and the setpoint is an unusual value (e.g. 123.4) so the match is unique, then change the setpoint on the front panel and read the candidate again to confirm.

    Read registers

    Write one register

    Writes the raw 16-bit value. Wrong addresses can change the controller's configuration.
